# 일본·대만 안내 문안 초안

2026-11-15. 외부 게시 전 검토용. 현재 Homebrew 버전에 이 기능이 있다는 주장이 아니다.

## 日本語

**読んでいる文章を、⌘Cを2回で翻訳。**

既存のAIサブスクリプションで使うMacメニューバーアプリ。原文を自動判定し、日本語・韓国語・英語・台湾の繁体字中国語・簡体字中国語に翻訳します。翻訳先は設定で変更できます。短い文章は手動で言語を選べます。

Apple Silicon / macOS 15以降。CodexまたはClaude Codeの契約・ログインが必要です。原文は選択したサービスに送信されます。画像OCRの言語対応はテキスト翻訳と別です。

## 繁體中文（台灣）

**閱讀中的文字，連按兩次 ⌘C 即可翻譯。**

使用既有 AI 訂閱的 Mac 選單列 App。自動偵測原文，支援日文、韓文、英文、台灣繁體中文及簡體中文。目標語言可在設定中變更；短句無法確定語言時可手動選擇。

需要 Apple Silicon、macOS 15 以上，以及 Codex 或 Claude Code 訂閱與登入。原文會傳送至所選服務。圖片 OCR 的語言支援與文字翻譯分開計算。

## 게시 전 확인

실제 앱 검증·모국어 문구 검토 후 landing/src/i18n에 별도 반영한다. 현재 랜딩은 ko/en 경로를 사용한다. Homebrew 설명 수정안: “Menu bar translator using your existing AI subscription”. cask 변경과 공개 사이트 배포는 승인 전 실행하지 않는다.
