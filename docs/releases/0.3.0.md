# deepK 0.3.0

일본어·중국어를 번역하거나 일본·대만 사용자와 함께 deepK를 쓰는 분께 업데이트를 권장합니다.

- 텍스트 번역 원문과 대상에 일본어, 대만 번체(대만식 표현), 간체를 추가했습니다. 한자만 있는 짧은 문장은 수동으로 원문 언어를 고를 수 있습니다.
- 사용자 언어에 따른 기본 대상과 설정의 대상 선택을 제공합니다. 한국어·영어·일본어·대만 번체 UI를 지원하며 간체 사용자의 UI는 영어로 표시합니다.
- Codex MCP 설정이 바뀐 뒤 남아 있는 이전 설정 이름 때문에 번역 연결이 실패하는 경로를 보완했습니다.
- Claude 의미 보존 지시와 일부 시간 상한 오류의 제한된 재검사를 추가했습니다. 재검사 시 같은 구독의 추가 요청 1회가 발생할 수 있습니다. 번역 정확도를 보증하지 않습니다.
- 새 버전을 선택적으로 안내하고 설정과 메뉴에서 수동으로 확인할 수 있습니다. ‘계속 사용’을 선택해도 번역·복사·삽입을 계속 사용할 수 있습니다.

기존 Codex 또는 Claude Code 구독을 사용하며 별도의 유료 API를 추가하지 않습니다. 이미지 번역은 기존 한국어·영어 범위를 유지합니다. Apple Silicon, macOS 15 이상이 대상입니다.

## Homebrew로 업데이트

메뉴 막대에서 deepK를 정상 종료한 다음 실행합니다.

```sh
brew update
brew upgrade --cask Geuni620/tap/deepk
open /Applications/deepK.app
```

0.2.0 이하 설치본에는 업데이트 확인 기능이 없으므로 최초 한 번은 이 수동 업데이트가 필요합니다. 배포 앱의 설정·구독 로그인은 유지하며 개발 앱 `deepK Dev`와는 별개입니다.

검증 범위와 알려진 한계는 [언어 지원 검증 기록](../evidence/ja-zh-support/validation.md)과 [업데이트 안내 동작](../app-updates.md)을 참고하세요. 자동 테스트·빌드 통과와 사용자 Mac의 실제 입력·삽입 검증은 구분합니다.
