# deepK 0.2.0

선택한 글과 이미지를 기존 ⌘C 두 번으로 같은 번역창에 가져옵니다. 이미지는 Mac에서 글자를 읽고, 선택한 Codex/Claude 공식 CLI에 글자만 보냅니다.

- 이미지 주소나 OCR이 실패해도 선택 글 번역과 복사를 계속합니다.
- 명시된 작은 표시 크기와 인라인 문맥을 함께 확인한 아이콘은 원래 작은 크기로 표시합니다.
- 이미지별 성공·실패를 나누고, 누락·원본 유지를 완료로 숨기지 않습니다.
- 같은 복사 HTML의 출처로 상대 주소를 해석하고 관찰한 공개 CDN을 지원합니다.
- 현재 이미지 번역의 언어 방향을 표시합니다.

정식 Debug·Release는 이미지 런타임을 포함하며, 합성 녹화·감사·테스트 명령은 배포 앱에서 제외합니다. 배포 시 실제 실행 파일의 기능 포함과 테스트 코드 제외, recipient 라이선스 파일을 검사합니다.

배포 대상: Apple Silicon, macOS15 이상. Intel/모든 게임·복잡 배경·모든 사이트 지원을 보장하지 않습니다. 지원하지 않는 항목은 원본 또는 부분 실패 안내로 남깁니다.

성능: 기존 클라이언트와 준비된 세션을 재사용합니다. 모델 생성 속도의 개선율은 이번 변경에서 측정하지 않았습니다. 합성 전후 영상과 실제 제공자 요청 검증은 구별합니다.

검증과 알려진 한계는 PR #12 및 experiments/image-translation/RESILIENCE_VALIDATION.md를 참고합니다.
