# 일본어·중국어 지원 업데이트 안내 초안

상태: 2026-11-15 로컬 검토용. 정식 릴리스가 공개됐다는 안내가 아니다. 사용자 설치 현황·실제 활성 사용자 수는 확인하지 않았다. 외부에 전송하거나 게시하지 않았다.

## 이 Mac에서 검토하기

0.3.0 로컬 패키지는 `deepK Dev`로 실행되며 기존 `/Applications/deepK.app`을 대체하지 않는다. Apple Silicon / macOS 15 이상이 대상이다. 기존 Codex 또는 Claude Code 구독을 사용하며 추가 유료 API는 없다. 로컬 패키지는 ad-hoc 서명이며 공증 배포본이 아니다. 기존 배포판의 권한과 설정을 공유하지 않아 입력 모니터링·손쉬운 사용을 별도로 확인해야 한다. 보안 설정을 끄거나 격리 속성을 일괄 삭제하는 방식으로 설치하지 않는다.

## 정식 릴리스 공개 후 사용할 안내문

> 일본어·중국어 문장을 번역하거나 일본·대만 사용자와 함께 deepK를 쓰는 분께 새 버전 업데이트를 권장합니다. 텍스트 번역에 일본어·대만 번체·간체를 원문과 대상으로 추가하고, 기본 대상 언어를 설정에서 고를 수 있게 했습니다. 이전에 일본어 선택 시 나타나던 한영 원문 제한 안내도 개선했습니다. Codex MCP 설정이 바뀐 뒤 번역 연결이 실패하는 문제를 함께 보완했습니다.
>
> 공식 릴리스가 공개된 뒤 해당 버전의 설치 파일과 업데이트 안내를 확인해 주세요. 이미지 번역 언어 범위는 텍스트 번역과 다르며 현재 한영을 지원합니다. 기존 AI 구독의 이용 조건과 사용량 제한은 계속 적용됩니다.

공개 전 빈칸: 실제 공개 버전·릴리스 URL·검증 범위·서명/공증 완료 여부·Homebrew 반영 상태. 공개 전에는 `brew upgrade`가 이 기능을 설치한다고 안내하지 않는다.

## 기존 0.2.0 사용자의 Paper MCP 오류 우회

`invalid transport in mcp_servers.paper`가 보이면 원문을 보존한 채 deepK 설정에서 Codex 연결을 해제한 뒤 연결 확인을 수행할 수 있다. 이는 Codex 로그아웃과 다르다. 이번 Mac의 배포 앱에서는 이 절차로 실제 번역이 복구됐다. 다른 Mac의 복구를 보증하거나 전역 MCP 설정 삭제를 권하지 않는다.


## 검증 후 보류 사유

66개 전체 방향 표본 중 Claude의 부정 반전·목적어 누락이 확인되어 일반 사용자 업데이트 권장을 보류한다. 추가 2회 성공은 실패 수정의 증명이 아니다. 현재 최신 공개 릴리스는 v0.2.0이며 조회 시 ZIP 다운로드 6회가 확인됐지만 활성 사용자 수·타인 사용 여부는 알 수 없다. 로컬 0.3.0 검토본은 별도 제공하되 정식 업데이트로 안내하지 않는다.


## 보완 후 상태

이전 실패는 기록으로 남긴다. 이후 의미 보존 지시와 한정된 시간 상한 검사를 보완했고, Claude 33개 재검증과 추가 9개 표본에서 이전 오류를 재현하지 못했다. 실제 권한 준비·사용자 두 번 복사·원래 TextEdit 삽입도 확인했다. 일반적인 번역 정확성이나 모국어 검토 완료를 보증하지 않는다. 정식 공개 릴리스는 여전히 별도 승인 전이므로 위 안내문을 외부 전송하지 않는다. 초기 로컬 패키지는 최신 코드의 패키지로 갱신해 제공해야 한다.
