# deepK

[한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · 繁體中文

選取文字後**連按兩次 ⌘C** 即可翻譯的 Mac 選單列 App，使用您既有的 ChatGPT 或 Claude 訂閱。

> 開發中功能：日文、台灣繁體中文及簡體中文的文字翻譯。公開的 Homebrew 版本可能尚未包含此功能。圖片 OCR 的語言支援範圍另計。

## 安裝與連線

需要 Apple Silicon Mac 及 macOS 15 以上版本。安裝公開版本：

```sh
brew install --cask Geuni620/tap/deepk
```

依照[開發說明](docs/development.md)，在 Codex CLI 使用 ChatGPT 帳號登入，或在 Claude Code 使用訂閱帳號登入。接著在 deepK 設定中選擇服務並確認連線。不會自動切換至額外付費 API；各服務的訂閱條款與用量限制仍適用。

## 使用翻譯

1. 在其他 App 選取文字，連按兩次 ⌘C。
2. App 會自動偵測原文語言。短詞或混合語言可能無法確定，請手動選擇原文語言。
3. 預設目標跟隨系統語言，可在設定的翻譯分頁修改。原文與預設目標相同時會翻譯成英文；若皆為英文，則提示選擇其他目標。
4. 在翻譯視窗變更目標後，按重新翻譯。此選擇只適用於目前工作階段。結果可複製，也能透過明確操作插入原本可編輯的位置。

文字翻譯支援韓文、英文、日文、台灣繁體中文及簡體中文。台灣目標會指定繁體字與台灣慣用語。只有共用漢字的內容可能無法確定語言。翻譯準確度不受保證。App 介面支援韓文、英文、日文及繁體中文；簡體中文系統顯示英文介面。

## 權限與隱私

偵測 ⌘C 使用輸入監控；插入原始位置使用輔助使用權限。修改權限前請先查看設定中的說明。翻譯原文及翻譯指令會傳送至所選外部服務。原文與翻譯不寫入運作記錄，但服務端的資料處理仍依提供者條款。標示為敏感的複製內容不會自動傳送；手動輸入不適用相同保護。

[安全性](SECURITY.md)・[授權範圍](docs/licensing.md)・[完整英文指南](README.en.md)。繁體中文介面與台灣用語目前為待審閱初稿。


Claude 文字翻譯若在可能性時間表達中加入原文沒有的上限，可能向同一模型多請求一次修正，因此增加訂閱用量與完成時間。若再次檢查仍不通過，會顯示錯誤。此有限檢查不保證一般語意準確度。
