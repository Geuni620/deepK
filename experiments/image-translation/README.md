# deepK 글·이미지 입력 POC

**선택 → ⌘C 두 번 → 기존 deepK 번역창** 흐름을 검증하는 실험 도구입니다. 이미지 런타임은 `DeepK/ImageTranslation`로 옮겼고 정식 Debug·Release가 `DEEPK_IMAGE_TRANSLATION`으로 포함합니다. 합성 녹화·감사·테스트 CLI는 `DEEPK_IMAGE_TRANSLATION_POC`로만 켭니다. [변경 전후 1~5 검증](RESILIENCE_VALIDATION.md), [초기 POC 검증 기록](VALIDATION.md)은 당시 리비전의 기록입니다.

## 입력과 실패 처리

- 선택 글 번역은 이미지 다운로드·OCR 성공을 기다리지 않습니다. 글 번역을 시작하는 동안 이미지는 메모리에서 준비합니다.
- 표시 크기가 명시적으로 가로·세로 24px 이하이며 인라인 문맥인 이미지는 작은 원본으로 표시하고 OCR하지 않습니다. CSS 픽셀 크기가 HTML 속성보다 우선합니다. 크기 정보가 없으면 보수적으로 본문 이미지로 취급합니다. `alt=""`·`aria-hidden`만으로 삭제하지 않습니다.
- 본문 이미지는 각각 불러오고 OCR합니다. 하나가 실패해도 다른 이미지와 글 번역은 계속됩니다. 읽지 못한 이미지는 자리 표시·개수 안내를 남기며, 글자가 없는 이미지는 원본을 유지합니다.
- 글 번역이 끝나면 이미지가 실패했어도 **글 복사**를 사용할 수 있습니다. 누락이 있는 상태는 전체 완료로 표시하지 않습니다.
- 인라인 이미지는 선택 글 안의 위치를 보존하고, 본문 이미지는 기존과 같이 세로로 배치합니다. 전체 웹 DOM·외부 폰트·모든 CSS 배치를 복원하는 구현은 아닙니다.
- X의 선택 HTML에서 IMG가 빠져도 DIV의 `background-image`가 남는 경우를 읽습니다. HTML은 libxml2로 데이터로만 파싱하며 스크립트를 실행하지 않습니다.

## 이미지 주소

자동 GET은 코드에 명시한 관찰된 공개 이미지 호스트에 한정합니다. X·Bluesky CDN·GitHub 이미지·검사한 문서 호스트와 제보된 사이트를 포함하며, 임의 호스트를 전부 허용하지 않습니다. 원본 서버에는 요청이 전달됩니다.

상대 주소는 같은 안정적인 클립보드 HTML에 있는 Chromium 출처 URL을 기준으로 해석합니다. 출처가 없으면 추측하지 않고 해당 이미지만 실패 처리합니다. HTML의 임의 base 태그를 신뢰하지 않습니다.

HTTPS·자격 증명 없는 URL·443 포트만 허용하고 리다이렉트도 같은 규칙을 적용합니다. 쿠키·인증 저장소·디스크 캐시 없는 메모리 세션을 사용합니다. PNG/TIFF·이미지 파일·HTML의 base64 이미지도 받을 수 있습니다. 붙여넣기·파일 드래그·화면 스캔은 보조 경로입니다.

## 번역과 표시

로컬 Apple Vision이 한국어·영어 글자와 위치를 읽습니다. 선택한 Codex/Claude 공식 CLI와 기존 AppModel 클라이언트·모델·Fast 설정을 재사용하며 엔진을 자동 전환하지 않습니다. 제공자에는 선택 글/OCR 글자와 블록 번호만 전달하고, 이미지 바이트·경로·URL·좌표·파일명·이미지 메타데이터를 추가하지 않습니다.

선택 글과 이미지 번역이 별도 요청 단계가 될 수 있습니다. 닫힌 블록부터 표시하고, 누락된 블록만 한 번 다시 요청합니다. 모델 전체 생성 속도가 빨라졌다는 의미는 아닙니다.

이미지는 네이티브 뷰로 표시합니다. 단색 배경의 글자 픽셀을 복원하고 원래 배경·글자색·굵기·배치를 추정하며, 안전하지 않은 영역은 원본을 유지합니다. 작은 글자는 약16pt가 되도록 표시 배율을 조절합니다. 선택적 로컬 MI-GAN 모델은 `./scripts/setup-image-inpaint-model.sh`를 명시적으로 실행해야 받으며 일반 빌드에서는 다운로드하지 않습니다. [모델 고지](THIRD-PARTY-NOTICES.md)를 참고하세요.

## 실행

macOS15 이상·Xcode Swift6가 필요합니다.

~~~sh
./scripts/image-translation-poc.sh --test       # 합성 회귀, 제공자 호출 없음
./scripts/image-translation-poc.sh              # 빌드 후 해당 POC 열기
./scripts/image-translation-poc.sh --open       # 같은 경로의 빌드 다시 열기
./scripts/replay-image-resilience.sh before    # 합성 before 영상 재현
./scripts/replay-image-resilience.sh after     # 합성 after 영상 재현
~~~

앱 경로는 `.build/image-translation-poc/deepK Rich POC.app`, ID는 `com.deepk.poc.rich-selection`입니다. 설치된 deepK를 종료하거나 TCC DB를 바꾸지 않습니다. 개발 인증서가 있으면 고정 서명을 사용합니다. 입력 모니터링은 전역 ⌘C 두 번에, 화면 기록은 명시적 스캔에만 필요합니다.

영상 재현은 서로 다른 테스트 앱에서 같은 합성 입력을 실제 TranslationView로 실행합니다. 이미지/번역 응답을 고정하며, 다른 앱 화면이나 사용자 클립보드를 읽지 않습니다. 물리적 단축키·실제 웹사이트 복사·모델 속도 증거로 제시하지 않습니다. 기존 실제 Codex 합성 녹화 명령은 `--record-synthetic-demo`입니다.

`--resilience-live`는 명시적인 환경 opt-in·감사 프록시·합성 출력 경로가 필요한 테스트 진입점입니다. 현재 선택 제공자가 Codex일 때만 실행하고, 고정 합성 선택 글만 보냅니다. 일반 입력에 감사 프록시·보고서·녹화를 적용하지 않습니다.

## 콘텐츠 수명과 제한

운영자 서버·분석·관리 화면·원문 첨부 진단을 추가하지 않습니다. 사용자 원문·이미지·OCR·번역문을 자동 로그·보고서·스크린샷·임시파일에 저장하지 않습니다. 처리·표시에 필요한 상태는 메모리에 두고 입력 교체·닫기·종료 때 취소·정리합니다. 명시적으로 생성한 합성 표본과 검증 산출물만 저장합니다.

클립보드는 HTML·이미지와 출처를 읽기 전후에 ConcealedType/TransientType과 변경 버전을 확인합니다. 이 표시는 민감성 전체를 판별하는 기능이 아닙니다. 파일 입력은 클립보드 표시만으로 판별하지 못합니다. 공식 CLI·제공자·운영체제 자체의 보관은 별도 범위이며 전체 경로의 무저장을 약속하지 않습니다.

선택 HTML1MB(전역 복사 모니터512KB), 항목24개, 본문 이미지8개·합성1200만 화소, 원본30MB·4천만 화소, 외부 다운로드8MB, 긴 변3200px, 이미지당 OCR160줄로 제한합니다. 초과하거나 지원하지 않는 항목은 부분 실패로 남깁니다.

실제 전역 단축키와 X·Bluesky·GitHub·문서 모든 페이지의 앱 E2E, 게임·전체 화면·다중 Space·장식 글꼴·복잡한 배경·선택적 모델 품질은 추가 검증이 필요합니다.
