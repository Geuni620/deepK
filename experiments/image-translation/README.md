# deepK 이미지 입력·번역 POC

기존 deepK 번역창의 입력에 선택한 글과 이미지를 자동으로 가져오는 macOS 실험입니다. 일반 앱 빌드에는 `DEEPK_IMAGE_TRANSLATION_POC` 분기가 포함되지 않습니다. 정책 문서와 배포 앱은 이 실험에서 수정하지 않습니다.

## 입력 방식

X에서 본문과 이미지가 있는 구간을 선택하고 기존처럼 **⌘C 두 번**을 누릅니다. X는 `user-select:none`인 IMG를 복사에서 제외하지만, 선택한 HTML의 DIV에는 `background-image` 주소가 남을 수 있습니다. 이 주소를 읽어 원본 이미지 서버에서 메모리로 가져옵니다. 확장 설치, 별도 이미지 붙여넣기, 두 번째 번역창이 필요하지 않습니다.

`backface-visibility:hidden`은 보이는 이미지의 렌더링 속성이므로 `visibility:hidden`과 구별합니다. 선택된 fragment만 libxml2로 읽고 스크립트·숨긴 요소를 건너뜁니다. HTML을 웹 페이지로 실행하지 않습니다. 같은 IMG/CSS 주소는 중복해서 읽지 않습니다.

자동 외부 불러오기는 현재 관찰·검증한 **HTTPS `pbs.twimg.com`**에 한정합니다. 로그인·쿠키·자격 증명·디스크 캐시 없는 세션으로 이미지 GET만 요청하고, 다른 호스트/비HTTPS로 리다이렉트하지 않습니다. 원본 이미지 서버에는 요청이 전달됩니다. 다른 사이트의 이미지 주소, 복사에 아예 정보가 없는 이미지, 인증이 필요한 이미지는 지원을 보장하지 않습니다. 이런 경우 이미지를 누락한 채 완료했다고 표시하지 않습니다.

직접 복사한 PNG/TIFF, 로컬 파일, HTML에 포함된 이미지 데이터도 기존 입력에서 받습니다. 이미지를 기존 입력으로 끌어 놓거나 ⌘V로 붙여넣는 것은 선택 가능한 보조 경로입니다. 화면 스캔은 뷰파인더 버튼으로 명시적으로 시작하는 별도 보조 경로이며, ⌘C 두 번을 자동 스캐너로 바꾸지 않습니다.

복수 이미지는 원래 픽셀 크기대로 위에서 아래로 배치합니다. 이미지 바깥의 선택 글은 같은 입력의 위쪽에 표시하고 이미지 OCR과 함께 번역합니다. 웹페이지 전체의 DOM 배치·외부 폰트·이미지 사이 글의 정확한 위치까지 복원하는 구현은 아닙니다.

## 표시와 번역

기존 번역창의 왼쪽은 원본 이미지, 오른쪽은 번역 이미지입니다. 별도 POC 창·WebKit 이미지 표시·PNG/base64 왕복 없이 네이티브 이미지 뷰를 씁니다. 이미지 속 문단과 줄별 위치를 로컬 Vision OCR로 읽고 기존 AppModel의 Codex/Claude 클라이언트와 선택 모델을 재사용합니다.

이미지 영역은 링크용 태그 대신 독립된 `<rN>` 블록으로 번역합니다. 닫힌 블록은 스트리밍 도중 표시하고, 누락된 영역만 한 번 다시 요청합니다. 중복 ID는 해당 영역만 거절합니다. 글자 인식 오류를 숨기지 않고 완료·부분 성공·실패를 구별합니다.

불러오기·OCR·응답 대기·문장 생성·이미지 반영 단계를 구별하고, 실제 생성 중인 글과 반영한 영역 수를 보여줍니다. 이미지 영역을 선택 글보다 먼저 요청하며, 완성된 영역은 전체 응답을 기다리지 않고 반영합니다. 이는 첫 결과를 일찍 보여주는 처리이며 제공자 모델 자체의 생성 속도를 높인다는 뜻은 아닙니다.

기본 읽기 크기는 이미지의 작은 본문이 화면에서 약 16pt가 되도록 확대합니다. 원본 픽셀의 글자 크기를 바꾸는 대신 표시 배율을 조절하며, 화면 맞춤·수동 확대도 지원합니다. 채팅의 이름·시간 줄은 본문과 분리하고, 원문과 같은 응답이면 해당 픽셀을 그대로 둡니다. 긴 번역은 다른 글자와 겹치지 않는 빈 배경을 확인한 경우에만 한 줄을 추가합니다.

단색·그라디언트 배경은 주변 색으로 글자 픽셀만 복원하고 원래 색·크기·굵기·정렬을 추정합니다. 원본 줄 위치와 번역문 전체가 들어가는지 검사합니다. 넘치거나 복원할 수 없는 영역은 원본을 유지하고 사유를 표시합니다. 흰 사각형으로 덮지 않습니다. 번역문을 별도 텍스트로 확인하는 버튼도 있습니다.

복잡한 배경에는 선택적인 로컬 MI-GAN Core ML 모델을 사용합니다. 설치는 `./scripts/setup-image-inpaint-model.sh`를 명시적으로 실행해야 하며, 일반 테스트·빌드에서 모델을 다운로드하지 않습니다. 고정 ref와 Git blob 해시를 검사하고 모델·원문 라이선스를 로컬 POC에 포함합니다. [모델 고지](THIRD-PARTY-NOTICES.md)를 참고하세요. 장식 글꼴의 정확한 복원, 모든 게임 배경·외곽선·그림자의 품질은 검증되지 않았습니다.

## 실행·검증

macOS 15 이상과 Xcode Swift 6가 필요합니다.

[검증 결과와 합성 화면](VALIDATION.md)에 실행한 검사와 미확인 범위를 구분했습니다. 초기 WebKit 별도 창과 별도 콜드 번역 클라이언트 실험은 현재 실행 경로에서 제거했습니다.

```sh
./scripts/image-translation-poc.sh             # 빌드 후 테스트 앱만 다시 열기
./scripts/image-translation-poc.sh --open      # 검증한 기존 빌드 다시 열기
./scripts/image-translation-poc.sh --test      # 오프라인 합성 검사
DEEPK_IMAGE_POC_LIVE=1 ./scripts/image-translation-poc.sh --scan-live-smoke
```

빌드는 `.build/image-translation-poc/deepK Rich POC.app`을 사용하며 식별자는 `com.deepk.poc.rich-selection`입니다. 설치된 deepK를 종료하거나 TCC DB를 변경하지 않습니다. Apple Development 인증서가 있으면 고정 서명을 사용합니다. `DEEPK_POC_SIGNING_IDENTITY`/`DEEPK_SIGNING_IDENTITY`로 지정할 수 있고, 없을 때만 임시 서명 경고를 출력합니다. 입력 모니터링은 ⌘C 두 번에, 화면 기록은 명시적인 화면 스캔에 필요합니다.

`--test`는 합성 안내판의 한국어 재OCR, 회색·파란 2열 카드 문단과 테두리 픽셀 보존, 긴 번역의 원본 유지, CSS 이미지 추출·중복·숨김·호스트 제한, 부분 스트리밍/중복 ID를 검사합니다. 기존 텍스트·서식·민감 클립보드 회귀 검사도 별도로 실행합니다. 합성 산출물만 Git 제외 `.build/image-translation-poc/synthetic/`에 남깁니다.

`synthetic-translation-window.png`는 실제 `TranslationView`를 화면 밖에서 실행해 그린 결과입니다. 응답은 직접 준비한 합성 번역문이며, 창을 열거나 전역 단축키·화면 기록·실제 제공자를 사용하지 않습니다.

`--record-synthetic-demo`는 이미 빌드된 앱을 다시 열어 **해당 앱의 합성 번역창 하나만** 녹화합니다. 다른 창과 오디오는 포함하지 않습니다. `synthetic-x-selection.html`을 브라우저에서 복사하면 같은 이미지 입력 경로로 재생합니다. 현재 자동 시연은 시스템 키 입력 조작을 제외하며, 창 제목·검사 JSON에도 이 제한을 표시합니다. 시스템 ⌘C 두 번을 직접 누른 영상으로 제시하면 안 됩니다. 허용된 합성 표본과 정확히 일치하는 복사만 시연에 받아들입니다.

Codex 선택 시 녹화의 실제 stdio 요청을 `audit-codex.py`로 중계하여 입력 항목이 텍스트뿐인지, source가 합성 OCR/선택 글 배치와 정확히 같은지, 이미지·경로·메타데이터가 없는지 검사합니다. 본문 없이 검사 결과만 기록합니다. 도구 차단과 일회성 스레드 설정도 확인합니다. 이는 **앱→공식 CLI JSON-RPC 경계** 검사이며 제공자의 전체 HTTP·처리·보관 감사는 아닙니다. 일반 GUI 입력은 이 중계나 보고서를 사용하지 않습니다.

## 콘텐츠 처리 범위

사용자 이미지·원문·OCR·번역문을 운영자 서버·관리 화면·분석·진단 전송으로 수집하지 않습니다. 익명화한 콘텐츠 수집도 없습니다. GUI 처리에 필요한 이미지·텍스트·복원 마스크와 결과만 메모리에 두고, 입력 교체·창 닫기·앱 종료 때 참조와 진행 작업을 정리합니다. 사용자 콘텐츠를 임시 이미지 파일·자동 보고서·스크린샷으로 보존하지 않습니다. 위의 명시적인 합성 검사·녹화는 직접 만든 표본만 받는 별도 경로입니다.

ConcealedType/TransientType은 클립보드 HTML·이미지를 읽기 전후에 검사합니다. 표시가 없다고 콘텐츠의 민감 여부까지 판별되는 것은 아닙니다. 파일 열기·드래그는 클립보드 표시만으로 민감 여부를 판별할 수 없습니다.

번역 제공자에게는 읽어낸 글자만 기존 공식 CLI로 보냅니다. 이미지 파일·원본 바이트·이미지 주소·좌표·파일명·메타데이터를 모델 입력에 추가하지 않습니다. 이미지 속 지시문도 번역 데이터로 취급하며 기존 도구 차단·환경 제한·세션 격리를 유지합니다. 제공자·공식 CLI·운영체제의 보관은 별도 범위이므로 전체 경로에서 어디에도 저장되지 않는다고 약속하지 않습니다.

## 제한

HTML 1MB(⌘C 두 번은 기존 512KB), 이미지당 OCR 160줄, 선택당 최대 8개 이미지, 원본 30MB·4천만 화소, 외부 다운로드 8MB, 긴 변 3200픽셀로 제한합니다. 여러 이미지 합성은 1200만 화소까지입니다. 너무 긴 문단·선택 글은 나누어 입력해야 합니다.

실제 X의 선택 복사에서 IMG 0개인 HTML의 CSS 이미지 1개를 새 파서로 읽고 원본 CDN에서 메모리로 불러오는 것을 확인했습니다. 본문·이미지는 로그나 파일로 남기지 않았고 원래 클립보드와 선택 상태를 복구했습니다. 이 검사는 실제 콘텐츠를 제공자에게 보내지 않았습니다. 실제 사용자의 마우스 드래그·전역 단축키·권한 체험과 모든 사이트·게임 품질을 대체하는 검증은 아닙니다. 속도 개선의 전후 비교는 별도로 측정해야 합니다.
