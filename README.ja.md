# deepK

0.3.0以降は新しいバージョンを1日1回確認し、任意で更新できます。設定で自動確認を無効にしても翻訳・コピー・挿入は使えます。GitHubへの確認に翻訳内容やアカウント情報は含めません。0.2.0以前は最初の1回だけ `brew update` と `brew upgrade --cask Geuni620/tap/deepk` を実行してください。

[한국어](README.md) · [English](README.en.md) · 日本語 · [繁體中文](README.zh-TW.md)

選択した文章を **⌘Cで2回コピー**すると翻訳するMacメニューバーアプリです。既存のChatGPTまたはClaudeのサブスクリプションを使用します。

> 開発中の機能：日本語・台湾の繁体字中国語・簡体字中国語のテキスト翻訳。公開済みのHomebrew版にはまだ含まれていない場合があります。画像OCRの対応言語とは別です。

## インストールと接続

Apple Silicon Mac、macOS 15以降が必要です。公開版のインストール：

```sh
brew install --cask Geuni620/tap/deepk
```

[開発手順](docs/development.md)に従い、Codex CLIにChatGPTアカウントで、またはClaude Codeに契約アカウントでログインします。deepKの設定でサービスを選び、接続を確認してください。追加の有料APIには自動切り替えしません。各サービスの利用条件と使用量制限が適用されます。

## 翻訳する

1. 別のアプリで文章を選択して⌘Cを2回押します。
2. 原文は自動判定されます。短い語句や混在した文章で判定できない場合は、原文の言語を手動で選んでください。
3. 既定の翻訳先はシステム言語です。設定の翻訳タブで変更できます。原文と同じ場合は英語に翻訳し、英語同士の場合は翻訳先の選択を案内します。
4. 翻訳ウインドウで翻訳先を変更したら再翻訳します。この変更はセッション内のみ有効です。結果はコピーでき、編集可能な元の位置には明示操作で挿入できます。

韓国語・英語・日本語・台湾の繁体字中国語・簡体字中国語に対応します。台湾向けの出力には繁体字と台湾の用語を指定します。共有する漢字だけでは言語を確定できない場合があります。翻訳の正確性は保証されません。

## 権限とプライバシー

⌘Cの検出に入力監視、元の位置への挿入にアクセシビリティを使います。権限を変更する前に設定の説明を確認してください。翻訳する文章と翻訳指示は、選択した外部サービスに送信されます。原文や翻訳を運用ログには保存しませんが、サービス側での取り扱いは提供元の条件に従います。機密としてマークされたコピーは自動送信しません。手動入力には同じ保護が適用されません。

Claudeの文章翻訳では、可能性を示す時間表現に原文にない上限が加わった場合、同じモデルに1回だけ修正を依頼します。契約の使用量と完了時間が増える場合があります。再確認にも失敗すればエラーを表示します。一般的な意味の正確性を保証するものではありません。
