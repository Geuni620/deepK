> 아래의 확정 사항·구현 범위·모델·비용·완료 기준은 당시 기록이며, 현재 구현 결정이나 비용 승인을 뜻하지 않는다.
> 원본은 별도 저장소에 보존했으며, 이 사본에는 참고 초안 표시와 경로·줄바꿈 표기 정리만 적용했다.

## 1. 추천 방향

**Cloudflare Workers AI를 첫 제공자로 평가한다.** Cloudflare를 써보고 새로운 기술을 경험하려는 사용자 의도에 맞고, Worker 안에서 AI binding으로 모델을 호출할 수 있다. 방문자는 로그인하지 않으며 운영자 계정의 사용량으로 처리한다. [Workers AI binding](https://developers.cloudflare.com/workers-ai/configuration/bindings/)

첫 평가 모델은 **Gemma 4 26B**다. 같은 Workers AI의 **Qwen3 30B**를 비교하고, 별도 제공자 후보는 **Gemini 3.1 Flash-Lite**로 둔다. 아래 추천은 통합 방식·단가·공식 모델 설명에 근거한다. 한국어 번역의 우열이나 응답 속도는 라이브 평가 전까지 확정하지 않는다.

| 제공자 / 모델 | 모델 ID | 입력 / 출력 100만 토큰 단가 | 이 프로젝트에서의 역할 |
| --- | --- | --- | --- |
| Workers AI / Gemma 4 26B | `@cf/google/gemma-4-26b-a4b-it` | US$0.10 / US$0.30 | 첫 평가 대상. 같은 Cloudflare 계정과 binding으로 연결 |
| Workers AI / Qwen3 30B | `@cf/qwen/qwen3-30b-a3b-fp8` | 약 US$0.051 / US$0.335 | 같은 인프라에서 비교할 대안 |
| Google Gemini API / Gemini 3.1 Flash-Lite | `gemini-3.1-flash-lite` | US$0.25 / US$1.50 | 공식 설명에 번역 용도가 포함된 외부 API 비교 후보 |

단가 출처: [Gemma 모델](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/), [Cloudflare 단가표](https://developers.cloudflare.com/workers-ai/platform/pricing/), [Gemini 단가표](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).

Gemma와 Qwen은 범용 언어 모델이다. 번역문만 반환하는 고정 지침을 사용하고 도구 호출은 붙이지 않는다. 추론 모드·완료 길이·실제 응답 계약은 각 모델 binding에서 검증하며, 지원 여부를 확인하지 않은 옵션을 가정하지 않는다. 여러 제공자로 자동 재시도하지 않고 검증 후 운영 모델 하나를 고정한다.

## 2. 같은 조건에서 보는 비용 예시

예시 조건: 요청 한 번에 **청구되는 입력 500토큰 + 출력 250토큰**, 총 **1만 번** 요청. 입력은 시스템 지침을 포함하고 출력은 제공자가 청구하는 추론 토큰을 포함한 총량으로 가정한다. 500자 제한과 500토큰은 같은 단위가 아니다.

- Gemma 4: `10,000 × (500 × 0.10 + 250 × 0.30) / 1,000,000` = **US$1.25**.
- Qwen3: 같은 계산으로 **약 US$1.09**.
- Gemini 3.1 Flash-Lite: 같은 계산으로 **US$5.00**.

이는 무료 할당·캐시 할인·호스팅·저장소·도메인·세금을 제외한 모델 사용료 예시다. 실제 토큰 수와 대기 시간은 모델 연결 후 측정한다. 금액 차이만으로 번역 품질을 추정하지 않는다.

## 3. 비용 제한 추천안

### 무료 범위에서 시작

- Workers Free는 Workers AI **계정 전체에 하루 10,000 Neurons**를 무료로 제공하며, 초과 사용에는 Paid 전환이 필요하다. Free 상태에서는 한도를 넘긴 작업이 실패한다. [공식 AI 요금](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- 먼저 현재 Cloudflare 계정의 Free/Paid 상태와 다른 서비스의 사용량을 확인한다. 이미 Paid인 계정의 초과 사용을 무료로 취급하지 않는다.
- 추천 운영 제한: **500자 / 익명 브라우저당 분당 3회·하루 10회 / 전체 하루 100회**. 이 수치는 초기 제안이며 사용자 수에 대한 보장이 아니다.
- 실제 모델의 최대 입력·출력량을 기준으로 무료 Neuron 할당의 남은 양도 고려한다. 요청 수만으로 모든 요청이 무료라고 단정하지 않는다.
- 한도를 소진하면 실제 체험을 잠시 중단하고 다음 이용 가능 시점을 안내한다. 정적 소개와 앱 배포 상태 안내는 유지한다.
- 이 단계에서는 모델 사용료 US$0을 목표로 한다. 계정이 Free이고 유료 서비스·선불 크레딧을 활성화하지 않은 조건이다. 계정 요금제를 이 계획만으로 변경하지 않는다.

### 유료 확장이 필요할 때

- **AI 사용료 월 US$5 상한**을 제안한다. 결제 동의나 유료 플랜 변경은 아직 없다.
- Workers Paid의 기본요금은 **월 최소 US$5**이며, AI 초과 사용료와 별개다. 기본료 US$5 + AI 상한 US$5인 **US$10 안팎의 초기 운영 목표**를 제안할 수 있지만 전체 계정 청구서의 하드 캡은 아니다. Worker·DO·로그 등의 초과 사용, 도메인과 세금은 별도다. [Workers 요금](https://developers.cloudflare.com/workers/platform/pricing/)
- 무료 할당을 받더라도 예산 카운터에서는 할인 전 모델 비용을 보수적으로 계산한다. 무료 할당을 가정해 유료 호출 허용량을 늘리지 않는다.
- 호출 전 최대 비용을 예약한다. 후보 예시는 한 호출 US$0.001 예약과 월 5,000회지만, 이는 선택 모델의 최대 입력·완료 토큰으로 최대 청구량이 그 이하임을 검증한 뒤에만 유효하다. 검증되지 않은 추정치를 정확한 비용 상한으로 구현하지 않는다.
- 사용량이 불명확한 실패 요청은 예약을 유지한다. 실제로 청구되지 않았다고 확인한 경우에만 조정하며 숨은 자동 재시도는 하지 않는다.
- 월 상한이나 일일 제한 중 하나라도 초과하면 모델 호출 전에 거부한다. 월 상한은 UTC 월 경계로 관리한다.

## 4. 제한 구현과 개인정보

- **SQLite 기반 Durable Object**에서 전체 요청 수와 예약 예산을 원자적으로 확인·차감한다. 저장하는 것은 기간별 카운터와 요청 예약 정보이며 원문·번역문이 아니다. SQLite 기반 DO는 Free에서도 사용할 수 있다. [DO 요금](https://developers.cloudflare.com/durable-objects/platform/pricing/)
- DO의 저장소 트랜잭션 안에서 예산을 예약하고 모델 호출은 트랜잭션 밖에서 실행한다. 병렬 요청·재시작·정산 실패가 상한을 우회하지 못하도록 검증한다.
- 익명 브라우저 식별자는 서버가 서명한 값으로 관리한다. 삭제·교체 가능한 브라우저 식별자는 로그인 사용자와 같은 강도의 개인별 제한이 아니므로 전체 예산이 최종 보호 장치다.
- Workers Rate Limiting binding을 추가한다면 빠른 반복 요청 제한에만 사용한다. 이 API는 위치별·eventually consistent이며 정확한 비용 회계용이 아니다. [공식 제한 범위](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/#accuracy)
- 카운터 확인 실패 시 호출을 허용하지 않는다. 예산 계산에 쓰는 모델 ID·단가·최대 청구량과 프롬프트 버전을 함께 고정한다.
- 원문·결과를 DO, KV, 로그에 기록하지 않는다. Cloudflare의 Workers AI 데이터 사용 설명과 실제 구현을 기준으로 개인정보 안내를 작성한다. Gateway 로깅과 별도 콘텐츠 저장을 기본으로 켜지 않는다. [데이터 사용](https://developers.cloudflare.com/workers-ai/platform/data-usage/)
- 외부 Gemini API를 선택하면 해당 제공자의 데이터 정책과 비용 카운터를 별도로 검토한다. 무료 티어와 유료 티어의 데이터 사용 조건을 같은 것으로 표시하지 않는다.

## 5. 모델 평가와 결정 기준

첫 검증은 한국어→영어 10개, 영어→한국어 10개로 제한한다. 채용 공고, 기술 문서, 메일, 숫자·부정 표현을 포함하고 동일한 원문과 번역 지침으로 비교한다.

1. 기대 의미와 용어 기준을 모델 출력과 독립적으로 준비한다. 정답 문장의 완전 일치만으로 품질을 평가하지 않는다.
2. 의미·숫자·고유명사·부정과 불확실성 표현을 확인한다. 원문에 없는 설명이나 추론이 번역문에 섞이지 않아야 한다.
3. 한국어 자연스러움, 기술 용어·코드·줄바꿈 보존과 출력 잘림을 확인한다.
4. 전체 응답 시간의 p50/p95와 실제 청구 토큰·Neuron 사용량을 기록한다. 빠르다고 미리 주장하지 않는다.
5. Gemma 결과가 기준을 만족하면 첫 모델로 고정한다. 만족하지 않으면 Qwen을 비교하고 필요할 때 Gemini와 비교한다. 추가 계정·키가 필요한 비교는 그 조건을 갖춘 뒤 수행한다.

비교의 실패 사례와 조건을 남긴다. 웹 체험이 Mac 앱에서 사용하는 Codex/Claude 구독 모델과 같은 품질·속도라고 표시하지 않는다.
