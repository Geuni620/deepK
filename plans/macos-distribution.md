# deepK 스크립트 기반 개인 베타 계획

갱신일: 2026-10-12
상태: 사용자 결정 반영. 기존 빌드·실행 및 로컬 패키징 도구는 준비됨. 다른 Mac 베타는 미검증이며 사용자 결정으로 후속 분리. 이 Mac의 Final Settings는 PR #29–#33으로 반영했고, 다른 Mac 베타와 공개 전 조건([공개 전 보안 점검](public-release-security.md))은 후속이다.

## 현재 결정과 우선순위

이번 제공 방식은 port-bar처럼 **소스를 받은 뒤 스크립트로 빌드·실행**하는 방식이다. 대상 제품은 deepK만이며, 먼저 본인 소유의 다른 Mac에서 비공개 베타를 진행한다. UI/UX는 2026-09-23 확인한 Final · Settings(`J6JTV`)와 창 크기 계획을 반영·검증한 뒤 테스트한다.

- 기본 실행: `git pull --ff-only` → `./scripts/build-and-run.sh`.
- 설치 파일 확인이 필요할 때만 `./scripts/package-release.sh --local` 사용. Developer ID 공증 배포본으로 표시하지 않는다.
- Apple Developer Program 결제·Developer ID 발급·공증, GitHub Release 게시, Homebrew tap/Cask, 앱 내 자동 업데이트는 이번 개인 베타의 필수 조건이 아니다. 현재 goal에 자동으로 포함하지 않는다.
- App Store 출시와 수익화는 현재 범위에 포함하지 않는다.
- 개인 베타 이후 소스를 오픈소스로 공개하려는 의향은 기록하되, 이번 요청을 저장소 공개 전환 승인으로 해석하지 않는다.

이 결정이 이전 서명·공증 배포 우선 계획보다 우선한다. 이미 구현한 패키징 코드는 유지하되, 배포용 경로를 실행하거나 기존 앱의 서명을 변경할 이유로 삼지 않는다.

## 준비된 도구와 실제 확인 범위

| 도구 | 역할 | 현재 근거 |
| --- | --- | --- |
| `scripts/build-and-run.sh` | 환경 확인·기존 앱 정상 종료·빌드·서명·실행 | 현재 Mac에서 프로젝트 밖 경로 실행과 키 감시 유지 확인 |
| `scripts/build.sh` | 빌드만 실행 | 현재 Mac 빌드 검증 |
| `scripts/setup-claude.sh` | 선택적으로 앱 전용 Claude CLI 준비 | 기존 설치 흐름 제공, 다른 Mac에서는 재설정 필요 |
| `scripts/package-release.sh --local` | 로컬 Release ZIP·체크섬·manifest | arm64/0.1.0/macOS 15 로컬 패키지와 압축 해제 후 서명·체크섬 검증 |

다른 Mac에서의 설치·로그인·권한·핵심 동작 성공은 아직 확인하지 않았다. 기존 Mac의 개발 인증서나 권한·로그인이 다른 Mac에 자동으로 전달된다고 가정하지 않는다.

## 다음 goal의 작업 순서

1. [Final Settings·창 크기 계획](window-size-and-layout.md)의 최신 기준을 구현한다. 이전 비교안을 혼합하거나 시안 예시 모델·버전을 실제 값으로 고정하지 않는다.
2. 확정한 UI를 작은 PR로 구현·검증하고 main에 반영한다. 크기 전환과 편집·번역·스크롤·복귀 상태 보존을 확인한다.
3. 아래 버전 관리 기준을 적용하고 베타에서 테스트할 정확한 버전·커밋을 정한다.
4. 본인의 다른 Mac에서 처음 설치, 평소 실행, 다음 버전 업데이트를 스크립트로 검증한다.
5. 발견한 문제를 수정하고 환경·버전·검증 결과·실제 화면 증거를 기록한다. 미검증 항목을 완료 처리하지 않는다.

## 다른 Mac 개인 베타 완료 기준 — 후속 작업

- [ ] 다른 Mac의 macOS 버전·CPU·Xcode/Swift 버전을 확인하고 기록한다. 현재 앱은 macOS 15 이상과 Swift 6 빌드 환경을 요구한다.
- [ ] 비공개 저장소 접근 권한을 사용해 처음 clone한 뒤 스크립트 하나로 실행한다. 특정 사용자 이름이나 개발자 checkout 절대 경로가 필수 조건이면 수정한다.
- [ ] 사용할 Codex 또는 Claude Code를 그 Mac에 설치하고 구독 로그인한다. Finder 실행에서도 CLI를 찾는지, 없을 때 필요한 조치가 안내되는지 확인한다. 토큰·개인 키를 복사하거나 저장소에 넣지 않는다.
- [ ] 그 Mac에서 입력 모니터링·손쉬운 사용을 허용하고 실제 감시를 확인한다. 인증서 유무에 따른 임시 서명 및 재빌드 후 재등록 가능성을 안내한다. 유료 가입은 소스 빌드의 필수 조건으로 두지 않는다.
- [ ] Chrome/TextEdit에서 ⌘C 두 번 → 자동 번역 → ESC 복귀 → 명시적 삽입을 실제 키보드로 확인한다.
- [ ] 작게/크게·설정, ⌘W 상주, 재실행, 캐시·중복 요청 방지, 빈 값/비텍스트·연결 오류 안내를 확인한다.
- [ ] 다음 버전으로 pull 후 스크립트를 다시 실행해 설정·제공자 선택·권한 유지 여부를 확인한다. 창의 미저장 번역 내용은 재시작 시 보존되지 않는 현재 동작을 안내한다.
- [ ] 안전한 예시 문장으로 실행 화면·문제 재현 절차를 기록한다. DeepL과의 단축키 충돌 및 확인한 지원 앱 범위도 명시한다.

## 최소 버전 관리

별도 업데이트 서버 없이 Git 버전과 스크립트를 기준으로 관리한다.

- [ ] 후보 규칙: Git 태그 `v0.1.0-beta.1`처럼 베타 회차를 구분하고, 앱 버전은 `0.1.0`, 빌드 번호는 증가하는 정수로 관리한다. 첫 실제 태그는 UI 확정·검증 뒤 선택하며 지금 생성하지 않는다.
- [ ] 빌드·실행 경로와 선택적 패키징 경로의 앱 버전·빌드 번호·소스 커밋 표시가 서로 일치하도록 정리한다. 현재 패키징 스크립트의 숫자형 버전 입력에 `-beta.1`을 그대로 넣지 않는다.
- [ ] 태그·커밋·변경 내역·테스트 환경을 함께 기록해 어느 버전을 테스트했는지 알 수 있게 한다. 이미 테스트한 태그와 파일을 다른 내용으로 덮어쓰지 않는다.
- [ ] 평소 업데이트는 main에서 `git pull --ff-only` 후 빌드·실행한다. 특정 베타 재현은 작업 중인 변경을 보존한 별도 checkout/worktree에서 해당 태그를 빌드한다. 사용자 변경을 강제로 reset하지 않는다.

## 개인 베타 이후의 별도 작업

다음 항목은 후속 검토이며 개인 베타 완료를 막지 않는다.

- 오픈소스: 라이선스·Git 이력의 비밀정보/개인정보·재배포 자산 점검, 설치·기여·버그 제보 문서, 테스트 자동화, 사용자 결정 후 저장소 공개.
  - 2026-10-12 [PR #52](https://github.com/Geuni620/deepK/pull/52)로 1차 보안 점검을 마쳤다. 번역 요청에 로컬 파일·민감 복사·부모 환경이 섞이는 경로를 막았고, 현재 파일의 개인 홈 경로를 `~`로 바꿨다.
  - 남은 조건은 [공개 전 보안 점검](public-release-security.md)에서 관리한다. Git 이력의 작성자 메일(회사 메일로 된 커밋 2개 포함)과 과거 커밋에 남은 개인 홈 경로는 이력을 다시 쓰거나 새 저장소를 만들어야 지울 수 있어 공개 방식을 먼저 정한다. 라이선스 파일과 보안 제보 경로도 아직 없다.
- 앱 파일 배포: 필요한 시점에 Developer ID·공증·다른 Mac의 Gatekeeper/업데이트 검증과 GitHub Release 게시. 기존 [배포 안내](../docs/distribution.md)는 이 경로의 참고 자료다.
- Homebrew: 공개 다운로드가 준비되면 개인 tap의 Cask에 버전·URL·체크섬을 연결하고 `brew upgrade`로 업데이트한다. Homebrew가 서명·공증을 대신하지 않는다.
- 자동 업데이트·DMG·App Store는 필요가 확인되면 별도로 계획한다.

번역 1초는 기존 합의대로 미달한 후속 개선 목표다. 개인 베타의 새 필수 합격선으로 바꾸지 않는다.

## 이전 실행 기록

아래 기록은 당시 준비 상태이며 현재 실행 범위는 위의 2026-09-23 결정이 우선한다.

## 2026-09-21 실행 기록

- `scripts/package-release.sh`와 [설치·배포 안내](../docs/distribution.md)를 추가했다. 기본 배포 모드는 Developer ID/Keychain 프로필을 요구하며 로컬 모드는 `--local`로 명시한다.
- 후보 버전 0.1.0, arm64, 최소 macOS 15.0으로 별도 Release 빌드와 로컬 ZIP 생성을 확인했다. ZIP 체크섬·manifest·앱 구성 및 압축을 푼 앱의 ad-hoc 서명 검증을 통과했다. 실행 중인 Debug 앱과 권한은 변경하지 않았다.
- 인증 정보 없는 배포 모드, 기존 산출물 덮어쓰기, 잘못된 버전은 빌드 전에 실패하는 것을 확인했다.
- 배포용 인증서 없음은 현재 Mac에서 재확인했다. 사용자에게 무료 소스 빌드/비공개 앱 배포/앱 파일 공개 방식과 Apple 유료 가입을 설명했고, 공개 범위와 유료 진행 여부는 아직 결정되지 않았다. 가입·결제·공증 제출·Release 게시를 진행하지 않았다.
- 스크립트 구현과 로컬 검증은 실제 Apple 공증이나 다른 Mac 설치 성공을 대신하지 않는다. 위 실제 배포 완료 체크리스트는 해당 증거를 확보한 뒤 갱신한다.


## 재개 중 범위 조정 — 2026-09-23

사용자는 현재 두 번째 Mac이 없어 해당 검증을 후속 작업으로 분리하기로 했다. 체크리스트는 미완료 상태로 보존하며 이번 goal의 즉시 완료 조건과 구분한다. 스크립트·버전·설치 안내는 계속 준비하고, 다른 Mac에서 실행됐다고 주장하지 않는다.
