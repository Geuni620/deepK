# 복사 원문 구조화 (PR B)

상태: 2026-10-12 1–4단계와 독립 리뷰 반영(스테이징만). 2026-10-13 결정 변경(선택된 탭은 코드 제목, 표시 없는 버튼 묶음은 본문, 복사 버튼은 어느 묶음에서나 꾸밈 글자, §5)과 복사 버튼 판정의 독립 리뷰(구 규칙, `role=tab` 제외, §2·§4)를 반영했다. 2026-10-13 PR A를 병합한 뒤 5단계(가드 연결·로그·정규식·저장소 테스트, §6)와 복사 버튼의 한국어·일본어 활용형(§2·§4)을 넣었다(스테이징만). 2026-10-13 PR #56 독립 리뷰의 가져오기·저장소 쪽 지적(I1 복사·삽입 펜스 스타일, C1 링크인 탭, C2 남는 꾸밈의 링크·칩, C3 `role=status`, C4 맨 `<pre><code>` 산문, C5 정렬 속도, C7 펜스가 되지 않은 블록의 링크, T5 캐시 키 테스트)을 반영했다(§2·§4·§7, 커밋 전). 2026-10-13 PR #56으로 main에 머지했다. 상세 설계와 조정 내용은 `~/.claude/plans/smooth-prancing-mitten/`(plan-B, reconcile §3·§4)에 있다.

## 1. 문제

- impeccable.style 문서의 탭형 코드 위젯을 Chrome에서 복사하면 text/plain에 `Most Agents`, `Codex`, `Copy`가 줄마다 들어온다. 이 글자가 원문 창, 캐시 키, 모델 입력에 그대로 섞였다.
- 가져오기는 버튼 글자를 HTML 쪽에서만 버리고 text/plain에서는 지우지 않았다. 그래서 정렬 허용치를 19/20까지 써서 겨우 통과했고, 위젯과 문단 한두 개만 고르면 링크와 칩이 모두 사라졌다.
- 복사한 HTML의 `<pre>`를 앱이 펜스로 만들지 않아서 코드 상자가 생길지는 모델 판단에 달려 있었다.

## 2. 결정

| 항목 | 결정 |
| --- | --- |
| 정체성 | 위젯 글자를 뺀 정리본이 `CapturedSource.plain`이다. 원문 창, 캐시, 중복 판단, 되돌리기가 모두 이 값을 쓴다(#51 수식 정리와 같은 방식). 복사 원본(`raw`)과 지운 범위(`removed`)는 진단용으로만 두고 `==`에서 뺀다. 캐시 키는 마크업 글도 실으므로 같은 글의 일반 복사, 펜스만 있는 복사, 다른 펜스(언어·제목)의 복사는 서로의 캐시를 쓰지 않는다. |
| 꾸밈 글자 | 버튼, `role=tab/tablist/toolbar/switch`, `role=status`, 잘라서 숨긴 글자, 줄 번호, `aria-hidden`·`user-select: none`을 기록한다. 버리지 않고 정렬에서 통째로 맞추거나 비용 0으로 건너뛴다. `role=button`인 링크(`<a href>`)는 행동 유도 링크라 링크로 둔다. `role=tab`은 링크여도 탭이다(Starlight, Bootstrap nav-tabs. Chrome이 복사 HTML의 `#tab-panel-0`을 절대 주소로 바꾼다). 탭의 주소는 패널을 보일 뿐이라 링크로 싣지 않는다. `role=button/switch` 링크는 페이지 주소를 알고 그 주소가 같은 페이지의 조각일 때만 컨트롤이다. 지우지 않은 꾸밈(40자를 넘는 클릭 카드·산문 도구 막대, 블록 옆이 아닌 버튼)의 글자는 본문처럼 링크·칩을 싣는다. 지운 줄의 꾸밈과 블록 제목 줄은 싣지 않는다. 잘라서 숨긴 `role=status`는 숨긴 글자다. |
| 탭 묶음 | 같은 부모, 또는 같은 `tablist`·`toolbar` 안에 나란히 있는 버튼·탭이 한 묶음이다. 탭 역할(`role=tab/tablist/toolbar`)이거나, 둘 이상이고 그중 정확히 하나에 선택 표시가 있으면 꾸밈 글자다. 선택 표시 없이(또는 둘 이상에) 나란한 보통 버튼은 페이지 본문(퀴즈 선택지)이라 남긴다. 혼자인 버튼(복사·실행·펼치기)은 그대로 꾸밈 글자다. 복사 버튼은 '둘 이상'에는 세지만 선택된 탭도 선택지도 되지 않는다(다음 행). 선택 표시는 `aria-selected`=true, `aria-current`=true/page, `data-state`=active, `data-selected`=true, 클래스 `active`·`selected`·`current`와 `-active`·`_active`·`-selected`로 끝나는 것(`is-active`, `tabs__item--active`)이다. `inactive`·`unselected`는 아니다. 켜진 토글(`aria-pressed`=true, `data-state`=on)은 같은 묶음에 다른 토글(`aria-pressed`, `data-state`=on/off)이 있을 때만 선택 표시다. 보통 버튼 옆 토글 하나(`Run` 옆 `Wrap`)는 탭이 아니라 설정이다. |
| 복사 버튼 | 버튼과 그 안쪽 요소(아이콘만 있는 버튼의 아이콘)가 복사를 말하면 복사 버튼이다. 글자, `aria-label`·`title`·`alt`, 이름에 `tooltip`·`title`·`tippy`가 든 `data-*` 툴팁(`data-tooltip`, `data-bs-original-title`, `data-tippy-content`), 아이콘의 `<svg><title>`은 구(句)로 본다. 라틴 글자는 첫 낱말이 `copy`·`copied`이고(대소문자 무시. `Copy`, `Copied!`, `Copy to clipboard`, `Copy command`), 한국어·일본어는 끝 낱말이 `복사`·`복사됨`·`복사하기`·`복사되었습니다`·`복사됐습니다`·`복사했습니다`·`복사 완료`, `コピー`·`コピーする`·`コピーしました`·`コピー済み`·`コピー完了`다(`코드 복사`, `코드 복사하기`, `コードをコピー`, `コードをコピーしました`). 활용형은 2026-10-13 기본값으로 넣었고, 끝 낱말 목록(`copyEndings`)만 고치면 되돌릴 수 있다. Material 아이콘 이름 `content_copy`도 같다. 이 낱말은 공백·문장 부호와, 가타카나와 다른 글자 사이에서만 나눈다(`コピーしました`는 `コピー`와 `しました` 두 낱말이다). 그래서 파일 이름·식별자(`copy.js`, `CopyButton.tsx`, `deep_copy.py`, `copyWithin()`)와 복사를 말하기만 하는 선택지(`A copy`, `Deep copy`, `복사본`, `복사하기 전에 저장`, `コピーを作る`, `Yes` 위의 툴팁 `Yes, it makes a copy`)는 아니다. 버튼·탭의 글자와 속성만 보고 본문 글은 보지 않는다. 클래스, `data-*` 이름, 아이콘 조각(`<use href="#icon-copy">`)은 이름으로 보아 글자가 아닌 것과 소문자 뒤 대문자에서도 나누고, 낱말 `copy`·`copied`·`clipboard`를 본다(`js-clipboard-copy`, `copyButton`, `fa-copy`, `data-clipboard-text`). 두 방식 모두 `Copyright`·`copycat`은 다른 낱말이다. 다른 `data-*` 값(`data-code`, `data-feedback`)은 페이지 자료라 보지 않는다. 자기에게 `role=tab`이 있는 탭은 복사 버튼이 아니다(이름이 파일·도구 이름이다. `copy.js`, `Copy object`). 복사 버튼은 혼자든 어느 묶음 안이든 꾸밈 글자이고, 선택된 탭도 선택지도 되지 않는다. 묶음의 '둘 이상'에는 세므로 선택 표시가 있는 버튼 하나와 복사 버튼(`npm`·`Copy`)은 탭 묶음이라 `npm`이 제목이 된다(1단계와 같음). 복사 버튼을 뺀 나머지가 하나이고 선택 표시가 없으면 혼자인 버튼이라 코드 옆에서 지운다(`Copy`·`Run`, 채팅의 `Copy code`·`Edit`, `Wrap`·`Copy`는 둘 다 지운다). 둘 이상이면 위 탭 묶음 규칙대로다. 퀴즈 선택지는 남고 옆 복사 버튼만 지운다. 선택 표시가 있는 탭 묶음은 안에 복사 버튼이 있어도(쓴 뒤 `is-active`로 표시돼도) 제목을 낸다. 지울 수 있는 곳은 다른 버튼과 같다. |
| 코드 제목 | 블록 바로 위 탭 묶음의 선택된 탭 글자는 그 코드의 제목이다(`Most Agents`는 명령이 어느 환경용인지 말한다). 정리본에서는 코드 첫 줄 바로 위 한 줄로 남고(다른 꾸밈 글자와 한 줄이었으면 그 줄이 정확히 제목이 된다), 모델 입력에서는 그 줄 대신 여는 펜스가 `title="…"`로 싣는다. 번역하지 않는다. 블록 하나에 탭 묶음이 여럿이면(OS 탭과 패키지 관리자 탭) 문서 순서대로 ` · `로 잇는다. 선택되지 않은 탭과 복사 버튼은 지금처럼 지운다. 그 코드는 복사본에 없으니 이름만 남으면 오해를 낳는다. |
| 지울 수 있는 곳 | 버튼·탭은 받아들인 코드 블록에 붙은 줄(빈 줄·다른 꾸밈 줄을 건너 이어진 줄 포함)이나 블록 줄의 양 끝에서만. 잘라서 숨긴 글자는 어디서나. 보이는 `role=status`는 복사를 알리는 글(복사 버튼과 같은 구 판정. `Copied!`, `Copied to clipboard.`)이면 어디서나, 아니면 버튼처럼 블록 옆에서만 지운다. 실제 지속 메시지(`Version 2.4 is the current stable release.`)를 `role=status`로 두는 디자인 시스템이 있어서다(2026-10-13 리뷰 C3 전에는 어디서나 지웠다). 줄 번호는 그 블록이 펜스가 될 때만. `aria-hidden`·선택 불가 글자는 보이는 본문일 수 있어 지우지 않는다. |
| 숨김 판정 | 클래스 이름만으로는 판정하지 않는다. Chrome이 복사 HTML에 계산된 `clip`, `clip-path: inset(50%)`, 1px 크기를 써 주므로 그 근거가 있어야 한다. `clip: rect()`는 네 값이 모두 0이나 1px일 때만 숨김이다(`rect(0px, 240px, 30px, 0px)`는 보이는 잘라내기). `not-sr-only`, `*-focusable` 클래스가 있으면 숨김이 아니다. |
| 안전 한도 | 줄 번호를 뺀 지울 글자가 64자를 넘거나, 줄 번호를 뺀 나머지 글자의 절반을 넘으면 정리를 포기하고 복사 그대로 둔다. 줄 번호는 받아들인 블록 옆 숫자만이라 어느 한도에도 넣지 않는다(짧은 줄의 긴 목록). 정리를 포기하면 복사 버튼·줄 번호가 줄 안에 남은 블록은 펜스를 씌우지 않는다. 버튼 글자 40자, 숨김·상태 글자 80자를 넘으면 본문으로 본다. |
| 코드 블록 | 코드 신호(`<code>`, 하이라이터 클래스, 언어)가 있는 `<pre>`가 줄 전체를 차지하면 앱이 펜스를 씌운다. 언어도 하이라이터 클래스도 없는 맨 `<pre><code>`는 줄이 코드처럼 보일 때만 후보다. Hacker News는 들여 쓴 글(대개 인용 산문)을 이렇게 그리고, 펜스가 되면 가드가 영어로 지키거나 두 번 낸다. 코드처럼 보이는 줄은 코드 문자나 명령 모양(`{`·`}`, 줄 끝 `;`, `f(x)`, ` -la` 같은 옵션, `==`·`=>`·`->`·`::`·`&&`, `a = 1`, 줄 머리 `$ `·`#!`·`//`·`# `·`>>> `·`<태그`)이 있거나 숫자·문장 부호가 아닌 기호가 30%를 넘는 줄이다. 그런 줄이 없으면 문장이 아닌 줄(네 낱말 미만이거나 기능어가 없음. 띄어 쓰지 않는 문자는 10자 이상이면 문장)이 절반을 넘을 때만 코드다(`npm install foo`, `make all`). 펜스를 끝내 씌우지 않은 블록(산문에 ``` 줄, 정리 포기, 검증 실패)은 산문이라 그 안 링크를 싣는다. 언어는 `data-language`, `language-x`, `lang-x`, `brush:`, pandoc `sourceCode x`, `highlight-source-x`, `hljs x`, `lang` 속성, 조상 클래스 순으로 읽는다. `TranslationMarkup`이 바로 태그로 읽는 소문자 태그만 쓰고, 나머지는 맨 펜스다. 코드에 ```가 있으면 백틱 4개 이상. 최대 32개. |
| 검증 사다리 | 펜스만 넣은 글을 파싱하면 정리본과 같고 블록이 1:1로 돌아와야 한다(제목이 있는 여는 펜스는 제목 줄과 코드 줄을 함께 대신하므로, 제목 줄을 뺀 정리본과 비교하고 제목 줄이 정확히 제목을 말하는지 따로 본다. 제목 없는 블록의 검사는 그대로다). 아니면 펜스를 빼고, 그다음 칩, 그다음 링크 순으로 내린다. 이미 Markdown 펜스를 쓰는 복사(Notion, Slack, 채팅)는 앱 펜스를 붙이지 않는다. |

## 4. 알려진 한계

- `<pre>`가 아닌 코드 위젯(CodeMirror, Monaco, Notion 웹)은 펜스를 붙이지 않는다.
- `<pre>` 밖 형제 언어 라벨(MDN `span.language-name`, VitePress `span.lang`)은 v1에서 본문으로 남긴다.
- 위젯이 많은 구간은 지울 글자가 64자를 넘어 정리를 포기한다. impeccable 위젯 하나에 `Codex`·`Copy` 9자이므로(선택 탭은 제목으로 남아 세지 않는다) 8개부터다. 이때 버튼 줄은 산문으로 남고, 블록은 줄 안에 꾸밈 글자가 없을 때만 펜스가 된다.
- 탭 묶음은 선택 표시로 가린다(§5). 그래서 복사 버튼을 빼고도 표시 없이 나란한 버튼이 둘 이상이면(역할 없는 `Run`·`Reset`·`Format` 도구 막대, `Run` 옆 켜진 `Wrap` 토글) 퀴즈 선택지와 구분할 수 없어 코드 옆이어도 본문으로 남는다. 같은 묶음의 복사 버튼만 지운다. 반대로 탭마다 부모가 따로 있고(`<li><button>`) `tablist`가 없는 탭 줄은 혼자인 버튼으로 보아 모두 지우고 제목을 만들지 않는다.
- 복사 버튼은 구(句)로 가린다(§2). 그래서 첫 낱말이 `copy`인 선택지(`Copy`, `copy`, `Copy the list`)와 역할 없는 탭(`class="tab active"`인 `Copy object`), 한국어로 끝이 `복사`나 그 활용형인 선택지(`깊은 복사`, `깊은 복사하기`)는 `Copy`·`Run`의 `Copy`와 구조로 구분할 수 없어 복사 버튼으로 본다. 그 버튼을 빼고 남은 버튼이 하나이고 선택 표시가 없으면 그 버튼도 혼자인 버튼이라 코드 옆이면 함께 지운다(`Reference`·`Copy`는 둘 다, 역할 없는 탭 `Copy object`·`Delete object`도 둘 다 지우고 제목이 없다). 남은 선택지가 둘 이상이면 그 버튼만 지운다(`move`·`del`·`copy`의 `copy`, `참조`·`값`·`깊은 복사하기`의 `깊은 복사하기`). 모두 복사 버튼이면 모두 지운다(`얕은 복사`·`깊은 복사하기`). 같은 규칙으로, 선택 표시가 있는 보통 버튼 하나와 복사 버튼이 한 묶음이면 그 버튼은 탭이 아니어도(`Run`) 제목이 된다(1단계와 같음).
- 놓치는 복사 버튼: 첫 낱말이 아닌 `copy`(`Click to copy`), 목록에 없는 한국어·일본어 활용형(`복사완료`, `복사할게요`, `コピーできました`), 다른 언어(`复制`, `Copier`), 이모지(`📋`), 한 낱말로 붙은 클래스(`copybtn`), 아이콘 글자에 바로 붙은 이름(`content_copyCopy`), 위 목록에 없는 `data-*` 툴팁(`data-tip`). 다른 단서가 없으면 보통 버튼이라, 옆 버튼과 함께 선택지로 남거나(`복사완료`·`실행` 둘 다 남는다) 혼자이면 코드 옆에서 지운다. `복사하기`·`실행`은 이제 `Copy`·`Run`처럼 둘 다 지운다. 버튼·탭 역할이 아닌 복사 컨트롤(`<div class="copy-btn">`, `<span class="copy">`, `<a href="#">Copy</a>`), `aria-expanded`가 있는 분할 복사 버튼, 제목 요소(`<summary>`) 안의 복사 버튼은 1단계처럼 지우지 않는다(클래스 이름만으로는 판정하지 않는다). 복사 버튼도 지울 수 있는 곳은 다른 버튼과 같아서, 코드와의 사이에 본문 줄이 있거나(선택지 위의 복사 버튼, `Copy`·`Download`·`Run`의 `Copy`) 본문과 한 줄에 붙어 오면 남는다.
- 코드 바로 옆의 40자 이하 보통 버튼은 혼자인 버튼이라 지운다. 그래서 `aria-expanded` 없는 FAQ 질문 버튼(`Why does it print twice?`)이 블록 바로 아래에 있으면 지워진다. `aria-expanded`가 있는 버튼(흔한 아코디언)과 제목 요소 안 버튼은 남는다. `Copy`·`Reference`가 둘 다 지워지는 것은 위 항목과 같다(2026-10-13 리뷰 C6, 그대로 둠).
- 맨 `<pre><code>`의 코드 판정은 줄 모양만 본다(§2). 문장처럼 읽히는 로그 한 줄(`The server started and is now listening on port 8080.`)은 산문으로 남고(펜스 이전과 같음), 코드 문자(`->`, `word(`)가 든 인용 산문은 펜스가 된다. 언어나 하이라이터 클래스가 있으면 판정하지 않는다.
- 보이는 `role=status`는 복사 알림이 아니면 블록 옆에서만 지운다. 블록에서 떨어진 다른 짧은 알림(`Saved`, `3 results`)은 원문에 남는다.
- `role=button/switch` 링크를 컨트롤로 보는 '같은 페이지 조각' 판정은 페이지 주소가 있어야 한다. 앱의 복사 가져오기(`copiedSource`)는 주소를 넘기지 않으므로 지금은 링크로 남는다. `role=tab`은 주소 없이도 탭이다.
- 버튼 글자 40자 한도는 가장 바깥 꾸밈 요소에 걸린다. `tablist` 안 탭 글자를 모두 합쳐 40자를 넘으면 탭 줄 전체가 본문으로 남고 제목도 없다(1단계와 같음).
- 제목은 코드 줄이 아니다. 줄 수, 블록 복사, `fences: .none` 일반 복사, 원래 앱 삽입은 코드만 쓰고 제목은 빠진다. Markdown 복사는 펜스 정보 문자열에 `title="…"`를 그대로 둔다. 기본 복사 형식인 '서식 포함'의 HTML(`TranslationMarkup.html`)·RTF(`ResultClipboard.rtf`)에는 제목이 들어가지 않는다.
- 선택된 탭이 코드 첫 줄과 같은 줄에 붙어 오면(꾸밈 글자가 코드 줄 앞에 이어 붙음) 제목으로 남기지 않고 지운다. 탭은 블록 위에 있을 때만 제목이다(아래 탭은 지운다).
- 앞 블록 바로 아래에서 이어진 탭 묶음은 앞 블록의 아래 탭일 수 있다. 그래서 그때는 블록에 가장 가까운 탭 묶음 하나만 제목이 되고 나머지는 지운다. 앞 블록 바로 아래 OS 탭과 패키지 관리자 탭이 함께 있으면 패키지 관리자 탭만 제목이 된다. 다음 블록에 위 탭이 없고 앞 블록의 아래 탭만 있으면 그 탭이 다음 블록 제목이 된다(글자로는 구분할 수 없다).
- 탭 줄과 코드 사이에 빈 줄이 있으면 제목을 만들지 않는다. 이때 선택된 탭은 1단계처럼 다른 탭과 함께 지운다. 정리는 빈 줄을 건너 탭 줄을 지우지만 제목 탐색은 빈 줄에서 멈추기 때문이다. Chrome은 `<p>`·제목 요소 뒤에만 빈 줄을 넣으므로 드물다.
- 가드는 블록 바로 위에 원문 그대로 다시 쓴 제목 줄만 지운다. 모델이 제목을 번역해 쓴 줄(`대부분의 에이전트`)은 모델의 산문으로 보고 남기므로 제목이 두 언어로 두 번 보일 수 있다. 이런 줄은 블록 자리를 셀 때도 산문으로 센다. 그래서 펜스를 뺀 블록 위에 번역된 제목 줄이 더해지면 블록 자리가 밀려 같은 코드 줄이 두 번 나올 수 있다. 제목 줄을 무작위로 더한 퍼저 2만 회 중 16건이고, 모두 이 경우다. 원문 그대로인 제목 줄만 더하면 0건이다(리뷰 전 525건). 반대로 원문 산문에 제목과 같은 줄(같은 이름의 소제목)이 있고 모델이 그 줄을 번역하면, 그 뒤 블록의 자리가 한 줄 밀린다. 다시 감싸기는 ±1 안이라 그대로 되고, 빠진 블록을 넣을 때만 한 줄 앞에 들어간다.
- 모델이 블록 펜스 안에 코드 줄을 더하면(맨 앞·맨 뒤) 그 줄은 블록 밖 산문으로 빠지고 `kept`로 센다. 가운데에 더한 줄은 버려진다(독립 리뷰에서 확인, 답 전체 펜스 규칙의 부작용).
- Codex 긴 문자열 보호: 채팅식으로 코드 줄 끝에서 닫힌 블록(`npm run build` 뒤 백틱 세 개)은 그 줄에서 끝난다고 본다. 백틱만 있는 줄은 여는 펜스 이상 길이·들여쓰기 3칸 이하일 때만 닫는다.
- 원본이 4,000자를 넘으면 정리본이 그보다 짧아도 파싱하지 않는다(B11).
- 언어를 모르는 맨 펜스는 링크·칩이 있을 때 닫는 펜스가 올 때까지 스트리밍 표시를 미룬다(B4).
- 원문을 고치면 구조 없이 번역하고, 정확히 되돌리면 구조가 돌아온다(B9). 오탐으로 지운 줄은 원본을 원문 창에 붙여 넣는 것 말고는 되살릴 방법이 없다.
- 언어 감지(TranslationStore.swift:1004-1018)는 코드가 섞인 정리본 전체로 한다. 블록 제외는 다음 작업이다.
- 픽스처는 직접 쓴 재현 페이지(`scripts/code-copy/page.mjs`)를 헤드리스 Chrome으로 복사한 것이다. 손으로 쓴 이전 픽스처와 비교해 Sphinx 표 줄 번호가 탭이 아니라 줄마다 나오고, Chrome이 선택 불가 글자와 숨은 탭 패널을 복사 HTML에서 빼는 것을 확인했다. impeccable 위젯의 줄 모양은 실제 복사(조사 기록의 모델 입력)와 같다. MDN·GitHub·Docusaurus·Sphinx 실제 사이트의 사용자 ⌘C 확인은 남은 일이다(`dump-pasteboard.swift` → `inspect-copied-source.sh` → `DEEPK_CODE_COPY_LIVE`).
- 가드: 모델이 답 전체를 펜스에 넣고 그 안의 블록 일부만 남기거나(첫 줄만 등) 산문과 같은 수의 줄로 섞으면, 줄이 한 번 더 나오거나 번역 한 줄이 빠질 수 있다(답 전체 펜스를 더한 퍼저 2만 회 중 40–50건, 리뷰 전 구현은 약 1,900건).

## 5. 선택된 탭 제목과 B–C 약속 (2026-10-13 결정 변경)

1단계는 선택된 탭을 포함해 탭 글자를 모두 지웠다. 그러면 impeccable의 `Most Agents | Codex`처럼 탭이 명령의 대상 환경을 말하는 위젯에서 그 정보가 사라진다(`Codex` 탭은 다른 명령을 쓴다). 사용자가 다음을 승인했다.

| 항목 | 정리본(원문 창·정체성) | 모델 입력 |
| --- | --- | --- |
| impeccable | `Most Agents\n/impeccable document\n…` | ```` ```text title="Most Agents" ```` |
| Docusaurus 탭 | `npm\nnpm install @docusaurus/core` | ```` ```bash title="npm" ```` |
| 코드 바로 위 퀴즈 선택지(`let`·`const`·`var`) | 그대로 남음(1단계는 지웠음). 같은 묶음의 복사 버튼만 지움 | 산문으로 남고 코드는 여전히 펜스 |
| 코드 바로 위 `Copy`·`Run`, `Copy code`·`Edit`, `Wrap`·`Copy` | 둘 다 지움(1단계와 같음) | 코드만 펜스 |
| 코드 바로 위 선택 표시된 `npm`과 `Copy` | `npm\nnpm install foo`(1단계와 같음. 사용자 확인 필요) | ```` ```bash title="npm" ```` |
| 코드 바로 위 선택된 탭 `copy.js`(파일 이름 탭) | `copy.js\nnpm install foo` | ```` ```bash title="copy.js" ```` |

**B–C 약속** (C 노트에도 같은 내용을 적는다)
- B의 여는 펜스: 백틱(`SourceCodeBlock.fence`개) + 태그 + ` title=` + 따옴표로 감싼 제목.
  - 태그는 블록 언어, 언어가 없고 제목만 있으면 `text`. 이때 `SourceCodeBlock.language`는 nil 그대로다(가드의 주석 규칙은 언어를 모를 때와 같다).
  - 큰따옴표로 감싸고, 제목에 큰따옴표가 있으면 작은따옴표로 감싼다.
  - 두 따옴표가 모두 있거나, 백틱·줄바꿈·제어 문자가 있거나, 앞뒤 공백을 자르고 안쪽 공백을 한 칸으로 줄인 뒤 40자를 넘으면 제목이 없다. 그때 선택된 탭은 다른 탭처럼 지운다(1단계와 같음).
- 제목이 없는 블록의 여는 펜스는 1단계와 바이트까지 같다. GitHub·MDN·Sphinx 픽스처는 바뀌지 않는다.
- C는 B의 것이든 모델이나 사용자가 쓴 것이든(```` ```js title="a.js" ````) 모든 펜스 정보 문자열에서 제목을 읽는다. 머리(태그나 `{…}`) 뒤 첫 `title=` 속성을 큰따옴표나 작은따옴표로 읽는다(`reading(of:)`와 같은 문법). C가 `CodeBlockChrome.swift`에서 직접 읽고 `TranslationMarkup.swift`(B 소유)는 고치지 않는다. 제목은 대소문자를 바꾸거나 번역하지 않고 그대로 보인다.
- C는 코드 머리띠에 제목을 보인다. Native는 `</> Most Agents · 1줄`(언어 이름이 있으면 `</> npm · Bash · 1줄`), GitHub는 `Most Agents`(`npm · bash`).
- 제목은 코드도 줄도 아니다. 줄 수, 블록 복사, `fences: .none` 일반 복사, 삽입은 코드만 쓴다(알려진 한계, §4).

**구현**
- 스캔: 버튼·탭마다 묶음(가장 가까운 `tablist`·`toolbar`, 없으면 부모 요소), 선택 표시, 탭 여부, 복사 버튼 여부(자기와 안쪽 요소의 속성과 아이콘의 `<svg><title>`. 글자는 스캔 뒤에 본다. `role=tab`이면 보지 않는다)를 기록한다. 선택된 탭과 선택지는 복사 버튼을 빼고 고르되, 복사 버튼도 '둘 이상'에는 센다. 다른 버튼 안의 버튼은 묶음에 들지 않는다. 본문으로 판정한 묶음은 꾸밈에서 빼되, 그 안의 숨김 글자(`sr-only` 등)는 안쪽 꾸밈 요소로 남는다(꾸밈 요소마다 바깥 요소를 기록해 다시 고른다).
- 정리: 블록 바로 위에서 지운 줄만 거슬러 올라가며 선택된 탭 글자를 찾는다. 그 줄들이 다른 블록 바로 아래에서 시작하면 가장 가까운 탭 하나만 쓴다(§4). 탭 안의 다른 꾸밈 글자(`(selected)` 같은 숨김 글자)는 제목이 아니다. 글자가 여러 줄에 걸치거나 한 줄에 두 탭 묶음의 선택 탭이 있으면 제목을 만들지 않는다. 남긴 제목 줄은 지운 줄 수, `removed` 범위, 정리 안전 한도에서 빠진다.
- 쓰기: 펜스를 쓸 때 제목 줄 자리에 여는 펜스를 쓴다. 펜스를 내리면 제목 줄은 산문으로 남는다.
