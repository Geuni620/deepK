# 번역 캐시와 확정 디자인 반영

2026-09-27 후속: 아래 완료 표시는 전체 입력/공백 캐시의 기존 범위다. 이후 사용자 goal 요청으로 문단 append의 기존 결과 유지·추가분 번역을 구현했다. 현재 범위와 검증 결과는 [증분 번역 계획](incremental-translation.md#12-1차-구현-결과--2026-09-27)을 따른다.

상태: 2026-09-19 사용자 승인으로 기존 goal에 추가했다. 캐시는 PR #19, 확정 디자인 연결은 PR #20·#23으로 main에 반영했다. 이후 캐시 계약은 PR #46(만료 항목 정리)과 PR #53(구조가 있는 원문의 키 분리)에서 바뀌었다.

## 검증 창 노출

사진의 `deepK verification fixture`는 단축키 검증용 입력 앱이다. 제품 오류 화면이 아니라 에이전트가 실제 앱 호출 검사를 위해 실행한 임시 창이다. 최신 프로세스 확인에서는 남아 있지 않았다. 이후 일반 테스트는 이 창을 열지 않으며 사용자 화면에서 GUI 검증을 자동 반복하지 않는다. 수동 실행하는 검증 도구도 환경 변수와 실행 인자 둘 다 있어야 시작하고, 작은 창에 검증용이라는 목적과 자동 종료를 명시한다.

## 캐시 계약

- [x] 번역 성공 결과만 메모리에 최대 32개, 5분간 보관한다. 5분은 저장한 시점부터 세며 다시 적중해도 늘어나지 않는다. 만료된 항목은 키와 관계없이 다음 캐시 조회·저장 때 지워 개수·바이트 한도를 차지하지 않게 한다(2026-10-07). 디스크·로그에 원문이나 결과를 저장하지 않는다.
- [x] 키는 제공자·모델·번역 지시 버전, 언어 방향/실제 언어 쌍, 정규화한 원문으로 구성한다. 증분 번역 이후에는 요청 단위(문서 전체/추가 문단)도 키에 넣는다. 2026-10-12 PR #53부터 Chromium 복사의 링크·인라인 코드 구조가 있는 원문은 그 구조(링크 번호와 백틱만, URL 제외)도 키에 넣고 별도 모드(`document-inline-v1`)로 저장해, 같은 글자의 일반 번역과 섞지 않는다. 캐시를 복원할 때 링크는 지금 복사한 URL 표로 연결한다.
- [x] 일반 문장의 앞뒤 공백, 끝에 덧붙인 엔터, 연속된 가로 공백과 줄바꿈 표기 CRLF/LF 차이는 같은 입력으로 본다. 단어 사이 공백을 전부 삭제하거나 대소문자·구두점을 바꾸지 않는다.
- [x] 내부 문단 구분·줄바꿈, 목록, 코드 표시(백틱·따옴표 쌍·연산자 등)나 들여쓰기가 있는 입력은 그대로 비교한다. 번역하기 전에 의미가 같은지를 일반적으로 판정할 수 없으므로 의미/형식을 바꿀 수 있는 편집을 임의로 캐시 히트 처리하지 않는다.
- [x] 공백만 바뀐 진행 중 요청도 재사용하되 결과를 최신 입력 버전에 연결한다. IME 조합 시작·실제 내용 변경·제공자 변경에는 기존 취소와 오래된 응답 차단을 유지한다.
- [x] 캐시 히트는 입력 디바운스나 네트워크 없이 반영하고, 복사·삽입은 현재 입력/호출 세션 검증을 계속 거친다. UI에는 필요할 때 ‘저장된 번역’으로 알려 준다. (이후 변경, 2026-10-13: 끝난 결과라 따로 알리지 않는다. [하단 막대](window-size-and-layout.md#하단-막대--2026-10-13사용자-피드백))
- [x] 캐시 만료(조회 없이 저장할 때의 정리 포함)·용량/바이트 한도와 축출 순서·모델/제공자/방향 분리·실패 미저장·진행 요청 재사용·코드/문단 보존을 테스트한다. 반복 입력이 빨라진 것과 새 문장 모델 속도는 구분해 보고한다.

## 디자인 기준

2026-09-23 이후 설정 기준은 `J6JTV`(Final · Settings)이며 [설정·창 크기 계획](window-size-and-layout.md)을 따른다(PR #29·#32). 아래 `Wtsit`/`bPiUX`/`l5GMR`과 `iSpFz`는 이전 비교 기록이다.

2026-09-20 최신 지정: `Wtsit`는 그룹형 시안 제목이며 실제 프레임은 `bPiUX`, 팝오버는 `l5GMR`이다. PR #23에서 계정·번역·권한 그룹과 관리 버튼을 반영했다. 아래 `iSpFz`는 이전 비교 기록이다. 메뉴 막대는 `mgb4W`의 Light/Dark ‘ㅋ’ 시안을 유지한다. 실제 새 화면과 권한 창 전환 검증은 [Mac 연동 기록](mac-integration-checks.md)에 있다.

MCP 확인: 현재 선택 `iSpFz`(설정 Popover), 확정 영역 제목 `wsp2M`(Section C · Final), 확정 메인 창 `iqniF`(Final · Main Window). wsp2M 자체에는 제목/설명/구분선만 있으며 메인 창은 별도 최상위 프레임이다. 디자인 캔버스의 ‘이 영역은 수정하지 않음’ 문구는 화면 내용이며 사용자 요청을 대체하는 지시로 취급하지 않는다. 앱 구현에 시안을 반영하고 원본 캔버스를 임의로 변경하지 않는다.

## 확인 결과

전체 단위/모의 통신 테스트 통과. 실제 앱에서 안전한 예시를 Haiku로 번역한 뒤 앞 공백·중복 공백·끝 엔터를 추가했고 ‘저장된 번역’ 표시를 약 21–38ms에 관측했다. 추가 요청이 없다는 근거는 요청 수를 세는 회귀 테스트이며 UI 측정은 표시 지연이다. 내부 줄바꿈과 코드 보존 테스트도 통과했다. 실제 메인 창 크기는 420×296으로 확인했다. 확정 앱 아이콘 k1D8Fw와 메뉴 막대 템플릿 ZlhFO를 MCP로 내보내 자산에 적용했다.

‘모든 설정’은 빠른 팝오버와 별도의 네이티브 창이다. 모달 시트가 앱 종료를 막던 실측 문제를 해결하기 위해 분리했고, 설정 창을 연 채 정상 종료를 확인했다. 연결 해제·복구와 긴 문단 독립 스크롤도 실제 앱에서 확인했다. 읽기 전용 대상·삽입 상태의 최종 검증은 새 서명 앱의 OS 권한 연결 뒤 수행한다.
